## 🎯 1. 추진 배경 및 목표

1. **패러다임의 혁신**: "보는 운동(Passive Viewing)"에서 "스마트폰 카메라로 직접 코칭받는 인터랙티브 운동(Interactive Training)"으로의 전환.
2. **리텐션 극대화**: 날씨(비/미세먼지)와 시간에 제약받는 야외 GPS 러닝을 보완하여, 실내 푸시업·스쿼트·윗몸일으키기까지 아우르는 365일 올인원 피트니스 생태계 구축.
3. **미니멀리즘 아키텍처**: 별도의 고가 스마트워치나 센서 없이, 웹 브라우저(On-Device AI)만으로 100% 무료·고성능 자세 판정 실현.

## 🤖 2. 온디바이스 AI 기술 아키텍처

```mermaid
graph LR
    UserWebcam[사용자 웹캠 입력] --> MediaPipe[Google MediaPipe Pose Engine]
    MediaPipe --> AngleCalc[관절 각도 및 평행도 Vector 계산]
    AngleCalc --> StateMachine{운동 상태 판정 머신}
    StateMachine -->|정자세 완료| CountXP[카운트 +1 & 볼트코인/XP 지급]
    StateMachine -->|자세 불량| AudioFeedback[실시간 음성/UI 교정 알림]
```

### 1) AI 엔진 채택
- **Google MediaPipe Pose (WASM / WebGL)**:
  - 33개 신체 관절 실시간 3D 랜드마크 추출 (60FPS 속도, 서버 통신 불필요)
  - 팔굽혀펴기: 어깨(11/12) - 팔꿈치(13/14) - 손목(15/16) 각도 감지 (90° 도달 및 수평성 검증)
  - 윗몸일으키기: 어깨 - 골반 - 무릎 사이 각도 수축 감지 (45° 이하 수축)
  - 스쿼트: 골반 - 무릎 - 발목 각도 감지 (90° 굴곡 및 무릎 쏠림 방지)
- **MediaPipe Hands**: 노터치(No-Touch) 제스처 인터랙션 (손바닥: 시작, 주먹: 정지).
- **MediaPipe Face Mesh**: 표정 및 피로도 감지.

## 🎨 3. UI/UX 및 데이터 엔지니어링 전략

1. **가운데 정렬 모바일 퍼스트 뷰 (Center-Aligned Container)**
   - 데스크톱/와이드 화면에서도 양옆에 사이버 네온 앰비언트 배경을 두고, 중앙 `max-width: 440px~480px` 영역에 모바일 앱 규격의 스마트 뷰포트를 고정 배치.
   - 모바일 PWA 및 PC 환경에서 일관된 1:1 앱 사용자 경험 유지.

2. **비디오 임베딩 (YouTube Iframe API 분할 듀얼 뷰)**
   - 상단 50%: 유튜브 트레이너 가이드 영상 (외부 임베딩으로 서버 비용 0원 달성)
   - 하단 50%: 실시간 웹캠 스켈레톤 라인 오버레이 뷰

3. **데이터 스크래핑/동기화 인식 문제 해결책**
   - 클라이언트 사이드 직접 스크래핑(CORS, Cloudflare 차단)을 지양하고,
   - **유튜브 공식 API(Data API v3)** 및 **Firebase Cloud Functions 기반 헤드리스 브라우저(Puppeteer/Cheerio) 프록시 파이프라인**을 통해 안정적인 데이터 파싱 보장.

## 🐣 4. 게이미피케이션(다마고치 펫) 시너지

- **러닝 완주**: 민첩성(AGI), 스피드 스탯 상승 ➔ 날렵한 형태(사이버울프 등)로 진화
- **푸시업/근력 운동**: 파워(STR), 근력 스탯 상승 ➔ 헤비 아머 폼으로 진화
- **싯업/플랭크 코어 운동**: 멘탈/체력(STA) 스탯 상승 ➔ 사이버 쉴드 폼으로 진화
- ➡️ 운동 종목에 따른 **멀티 클래스 펫 진화 트리** 완성.
