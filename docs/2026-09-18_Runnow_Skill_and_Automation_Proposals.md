## 1. 분석 개요
9월 14일~15일 간 진행된 Runnow 앱의 대규모 고도화(AI 케어팀 도입, 공공데이터 연동, PII 제거 상용화) 및 Web → React Native(Expo) 전환 운영표준 확립 과정을 면밀히 분석했습니다. 개발, QA, 마케팅 각 실무 에이전트들의 작업 병목을 해소하고, Runnow의 글로벌 상용화 및 향후 신규 앱 제작 속도를 극대화하기 위해 다음의 **5대 신규 스킬 및 자동화 시스템** 도입을 제안합니다.

---

## 2. 5대 핵심 스킬 및 자동화 제안

### 1) [Web → Expo 앱 원클릭 자동 전환 파이프라인 (Skill)]
- **분석 배경**: "웹 우선, 그 후 Expo 앱 복제 및 승격"이라는 전사 표준이 수립되었습니다. 하지만 매번 수동으로 폴더를 복제하고 Expo 래핑을 하는 것은 비효율적입니다.
- **제안 내용**: 웹 정본(Vanilla/Vite)의 빌드 결과물을 분석하여 자동으로 Expo PWA/TWA 템플릿에 이식하고, 안드로이드/iOS 크로스 플랫폼 검증(Capacitor/WebView 브릿지)까지 원클릭으로 완료하는 유나(프론트엔드) 전용 스킬 개발.

### 2) [상용 배포 전 PII 및 더미 데이터 스캐너 (Skill / QA 게이트웨이)]
- **분석 배경**: 상용 프로덕션(`promote:live`) 전환 시, 대표님의 실명 및 개인 이메일, VIP 테스트 패스 등을 수동으로 찾아 상용 중립 언어로 변경하는 리스크가 있었습니다.
- **제안 내용**: 코드베이스 내 하드코딩된 개인정보, 시크릿 키, '테스트용' 문구, 잔여 콘솔 로그 등을 정규식 및 AST 구조로 완벽히 스캔하여, 하나라도 적발 시 배포를 강제 차단하는 수호(QA) 에이전트용 보안 게이트웨이 스킬.

### 3) [공공데이터(식약처/기상청) 엣지 캐시 무중단 업데이트 (Automation)]
- **분석 배경**: 0ms 속도 보장을 위해 5만 건 이상의 공공데이터를 로컬 JSON 캐시로 구성하였으나, 이를 항상 최신 상태로 유지할 자동화 로직이 부재합니다.
- **제안 내용**: 백그라운드 크론(Cron) 스케줄러를 활용하여 매일 새벽 식약처 및 기상청 API를 호출, 신규 영양소나 날씨 규격 변동이 있을 경우 자동으로 JSON 캐시를 갱신하고 PR을 올리는 데이터 동기화 파이프라인.

### 4) [인스타 릴스/스토리 비디오 자동 렌더링 파이프라인 (Automation)]
- **분석 배경**: Remotion 기반 15초 비디오 생성기(`reelsGenerator.js`)가 탑재되어 2D 펫 기반 숏폼 생성이 가능해졌습니다.
- **제안 내용**: 유저가 의미 있는 마일스톤(치팅 방어 성공, 1주일 연속 러닝 등)을 달성할 시, 서버리스 환경에서 자동으로 15초 릴스 비디오를 렌더링하고 다운로드 링크를 제공하거나 마케터(하린)가 바로 광고 에셋으로 활용할 수 있게 하는 마케팅 자동화 파이프라인.

### 5) [다중 페르소나 E2E 모바일 시뮬레이터 (Subagent Skill)]
- **분석 배경**: 레오, 루나, 닥터케이 등 AI 코치 간의 스위칭, TTS, 캘린더 연동 등 시나리오가 매우 복잡하여 기능 추가 시마다 E2E 테스트 비용이 큽니다.
- **제안 내용**: 브라우저 서브에이전트가 iOS Safari, Android Chrome 환경으로 각각 위장(Spoofing)하여, 유저 페르소나별로 전체 플로우를 순회 테스트하고 스크린샷 4종을 자동 확보하는 시각적 회귀(Visual Regression) 스킬.
